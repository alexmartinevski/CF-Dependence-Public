**Files in the 17 November release:**

- `P04.pdf` — main article: sharp mixing, multilinear inequalities and centred interaction constants.
- `P04_GHZ_Companion.pdf` — supplement: square-wave harmonic proofs and the finite three-party GHZ witness.
- `P04_Supplementary_Material.zip` — reproducibility sources, exact-rational verification data and checking code.

These three files have **one shared publication DOI**. The supplement is not a separate publication. For the three-party constant, the lower bound is computer-assisted and the exact value remains open. Access the publication files via the published Zenodo record; this directory intentionally does not duplicate the release binaries.
